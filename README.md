# 巢记 ChaoJi v2.0

**免安装的本地富文本笔记应用** —— 一个单文件 HTML 前端 (`chaoji-v2.0.html`) + 一个可选的极简零依赖 Python 本地服务 (`server.py`)。

不需要安装任何软件、不需要管理员权限、不需要联网，所有笔记数据 100% 保存在你自己的 `.nbk` 文件里。

> 典型场景：公司管控办公电脑（无法装软件）、内网环境、跨平台/多浏览器公用终端。

---

## v2.0 重大升级亮点

### 1. 美学设计与视觉体系升级
- **三套高对比度语义主题**：内置 **🌿 竹青浅色（Light）**、**📜 暖杏护眼（Sepia）**、**🌙 曜石暗夜（Dark）** 三套符合 WCAG AA/AAA 标准的高对比度配色，一键切换并自动记忆。
- **现代卡片式页面列表与层次导航**：
  - 左栏笔记本与分区实时显示下属页面数徽章（Badge），重命名与删除按钮悬停优雅渐显，支持双击快速重命名；
  - 中栏升级为卡片列表，支持**📌 置顶徽章**、**双行正文摘要预览**、**字数统计**与**搜索关键词高亮**；
  - 右栏编辑区采用半透明毛玻璃吸顶头部，支持 **「标准阅读版心 / 宽屏模式」** 切换、**「Ctrl+\ 专注模式（折叠侧边栏）」** 以及 **「📑 自动目录大纲（TOC）」** 抽屉。
- **非阻塞式定制弹窗**：全面替换原生丑陋且易被内网策略拦截的 `prompt()` / `confirm()`，所有新建、重命名、删除确认均采用支持键盘快捷键的现代模态框。

### 2. 核心缺陷修复（Bug Fixes）
- **【修复数据安全隐患】彻底修复新建文件覆盖原 `.nbk` 文件的严重缺陷**：顶栏「📄 新建文件」会先检查当前未保存改动并解除旧 `fileHandle` 绑定，杜绝自动保存将空白状态静默覆写进旧文件；同时左栏「＋」专门用于在当前 `.nbk` 文件内新增多个笔记本。
- **【修复全文搜索局限】支持跨笔记本/跨分区全域搜索**：修复 v1.0 只能搜索当前选中分区的缺陷，支持「全域 / 本分区」一键切换、关键词 `<mark>` 高亮、路径标签展示及跨分区点击直达。
- **【修复工具栏与代码块体验】**：
  - 实时监听光标位置，动态高亮工具栏激活态（加粗、斜体、列表、代码、高亮）并同步更新段落级别下拉框；
  - 将「❝ 引用」独立为开关按钮，解决下拉框无法重复选择以取消引用的 Bug；
  - 修复 `<pre><code>` 代码块内按回车导致代码块碎裂、按 Tab 误变引用块的 Bug（支持 `Enter` 换行、`Ctrl+Enter` 跳出代码块）。
- **【修复图片缩放框残留】**：改用 `Pointer Events` 兼容触控与高分屏，滚动、窗口缩放或删除图片时实时同步/清理选框，并新增 **「25% / 50% / 75% / 100% / 删除」图片悬浮工具条**。
- **【修复 Markdown 与 Word 导出问题】**：修复行内代码内 `*`/`_` 被误解析为斜体的 Bug；支持 `- [ ]` 待办清单、连续多行引用合并、`==高亮==` 语法；修复 `DIV` 换行导出粘连及 Word 导出删除线 CSS 语法错误。
- **【增强 `server.py` 安全性与文件名兼容性】**：支持含空格、括号的 `.nbk` 文件名，补齐全部手拼 JSON 转义，新增写盘前 JSON 载荷完整性校验，并新增 `/api/rename` 与 `/api/delete` 接口支持在浏览器内直接重命名或删除服务器上的 `.nbk` 文件。

### 3. 易用性与跨端兼容性提升
- **跨浏览器保存降级（Firefox / Safari / 旧版内网浏览器）**：修复无 `showSaveFilePicker` 浏览器按 `Ctrl+S` 报错崩溃的问题，自动平滑降级为 `.nbk` 下载保存。
- **响应式与移动端/分屏适配**：支持窄屏/平板抽屉式导航菜单与触屏表格快捷操作栏（光标点入表格自动展开行列增删工具条，无需依赖右键）。
- **全局拖拽（Drag & Drop）**：直接把 `.nbk`、`.md`/`.txt` 或图片拖入窗口即可打开、导入或插入正文。
- **新增交互功能**：可勾选并持久化的 **☑ 待办清单**、页面 **📌 置顶**、**📂 跨分区移动页面**、**多种排序方式**、以及 **导出整本为独立 HTML 网页归档**。

## 快速上手

### 方式一：直接双击打开（零依赖浏览器文件模式）
1. 双击打开 `chaoji-v2.0.html`（推薦 Chrome / Edge / 360 极速 / Firefox / Safari）。
2. 点击「📄 新建文件」或「📂 打开」，按 `Ctrl+S` 即可保存为 `.nbk` 文件。

### 方式二：本地服务器模式（推荐有 Python 3 的环境，零弹窗无感自动保存）
```bash
python3 check.py                 # 可选：运行环境自检
python3 server.py                # 启动本地服务 (默认 http://127.0.0.1:8765/)
```
