# 巢记 ChaoJi

**免安装的富文本笔记应用** —— 一个 HTML 文件 + 一个可选的 Python 脚本。

不需要安装任何软件、不需要管理员权限、不需要联网，数据保存在你自己的文件里。

> 典型场景：公司管控办公电脑（无法装软件）、内网环境、公用终端。

---

## 这是什么

巢记是一个**类似 OneNote** 的笔记工具，长这样：

```
┌──────────┬──────────┬──────────────────────────────┐
│ 笔记本 🕮 │ 页面      │                              │
│  └ 分区▏ │  ├ 笔记A  │   页面标题                    │
│         │  ├ 笔记B  │   ──────────────             │
│         │  └ 笔记C  │   这里是富文本编辑区，          │
│         │          │   可以加粗、插入图片、粘贴截图…  │
└──────────┴──────────┴──────────────────────────────┘
```

- **笔记本 🕮** 就是一个 .nbk 文件，是最外层的容器
- **分区 📄** 隶属于笔记本，帮你在笔记本内分门别类
- **页面** 是你真正书写的地方，属于某个分区

三条数据铁律：

1. 你的笔记保存在 **.nbk 文件**里，不依赖浏览器缓存（浏览器缓存会被清理，文件不会被）
2. 拷走 .nbk 文件 = **换电脑无缝续写**
3. 服务只监听本机 127.0.0.1，**数据不出你的电脑**

## 30 秒上手（所有人必走的路）

**第 1 步 · 拿到文件**

把仓库里的 `chaoji-v0.5.html` 下载/拷贝到你电脑的任意**可写**目录，比如桌面。

**第 2 步 · 打开它**

用你身边的浏览器双击打开（360 企业安全浏览器、Chrome、Edge 都行，Firefox 也基本可用）。

**第 3 步 · 建一个笔记本**

1. 点顶栏「📂 打开笔记本」
2. 选择一个位置，把文件命名为 `我的笔记本.nbk` 保存
3. 完成——你现在有一个空白笔记本了

**第 4 步 · 写下第一页**

1. 左栏「＋」建分区（首次有默认分区，可跳过）
2. 中栏「＋」或按 **Ctrl+N** 新建页面
3. 输入标题，正文区打字。试试：选中文字点 **B** 加粗，或直接 **Ctrl+V 粘贴一张截图**

就这些。你已经会用巢记了。

## 保存是怎么回事（重要，值得花 1 分钟理解）

| 场景 | 怎么工作 |
|---|---|
| 你在打字 | 编辑过程中改自动暂存，**每 30 秒**悄悄写回 .nbk 文件 |
| 你按 **Ctrl+S** | 立即写回，标题旁徽章与状态栏显示「上次保存 14:32」 |
| 你忘了保存要关页面 | 弹窗拦你一下（数据在 .nbk 所以最多丢 30 秒改动） |
| 保存失败（磁盘满等） | 自动降级为「导出备份」下载一份副本，不让数据丢失 |
| 服务器模式下 | **直接 POST 给 Python 进程写盘**，连授权弹窗都没有，其他体验一样 |

**首次授权（仅浏览器文件模式）**：第一次 Ctrl+S 时浏览器会弹一个「另存为」对话框，选好位置命名 .nbk 文件后，浏览器就记住了这个文件——**以后 Ctrl+S 不再弹窗**，直接静默写回。这是浏览器安全设计（必须用户手势授权一次），不是巢记制造麻烦。

### 结构管理

| 操作 | 怎么做 | 快捷方式 |

**层级怎么看**：笔记本带 🕮 图标顶格显示；分区带 📄 图标缩进一档、条目更小——缩进表达"分区在笔记本里**面**"。

### 编辑

| 功能 | 怎么用 |
|---|---|
| 加粗/斜体/下划线/删除线 | 选中文字点工具栏 B/I/U/S（或右键菜单） |

| 高亮 | 工具栏 🖍 或右键→高亮选中 |
| **Tab 缩进** | 无选区时 Tab 插两空格；选中多行 Tab 整块缩进，**Shift+Tab 反向** |
| 插入图片 | 工具栏 🖼，或**直接 Ctrl+V 粘贴截图**（自动压缩到最长边 1280px） |
| **调整图片大小** | 点击图片出现蓝框，**拖右下角绿块等比缩放** |
| 全文搜索 | 中栏顶部搜索框（标题+正文都搜），回车跳第一条结果 |
| 自定义右键菜单 | 笔记本/分区/页面/编辑器**四处**都有，功能见各自菜单 |

### 导出

| 操作 | 怎么做 | 结果 |
|---|---|---|
| 导出当前页为 Word | 顶栏「📄 导出本页 Word」 | `.doc` 文件，Word 和 WPS 直接打开，样式/图片保留 |
| 导出整本备份 | 顶栏「导出备份」或 **Ctrl+Shift+S** | 带时间戳的 `.nbk` 副本，用于备份或多机转移 |

### 状态一目了然

- **标题旁小徽章**：`✓ 14:32`（已保存）/ `● 未保存`（有改动待写回）
- **底部状态栏**：文件名、上次保存时间、笔记本/页面数量统计

## 进阶用法

### 多台电脑之间同步

1. 电脑 A 上写完，**确保已保存**（标题旁出现 ✓）
2. 把 `.nbk` 文件拷到电脑 B（U盘/内网共享/公司允许的任何方式）
3. 电脑 B 打开巢记 → 「📂 打开笔记本」选中这个 .nbk → 继续

注意：两边**别同时编辑同一份**文件（没有云同步，最后写的会赢）。

### 服务器模式（推荐有 Python 的用户）

优点：**零弹窗、真正的自动保存、打开即上次状态**。

```bash
cd ~/notes                       # server.py 和 chaoji-*.html 放同一目录
python3 server.py                # 起服务，自动开浏览器到 http://127.0.0.1:8765/
```

可选参数：
```bash
python3 server.py --port 8899              # 换端口
python3 server.py --dir ~/mydata           # 数据目录
python3 server.py --no-browser             # 不要自动开浏览器
```

打开后逻辑：点「📂 选择笔记本」（页面顶部横幅处）→ 列出数据目录所有 .nbk → 序号选择/输入新名字新建。**之后所有保存都无感完成**。

不用的服务器了：终端 **Ctrl+C** 即停止，数据在 .nbk 文件里不会丢。

### 双模式自动切换

HTML 前端启动时会自动探测服务器是否在线：
- 有服务 → 服务器模式（状态栏显示「服务器模式: 文件名」）
- 没服务 → 自动退回浏览器文件模式（「打开笔记本」走文件选择对话框）

**同一份 HTML，同一份数据格式**，今天是服务器模式明天没有 Python 了，双击 HTML 继续，.nbk 文件通用。

## 环境自检（遇到问题先跑这个）

```bash
python3 check.py
```

**server.py 是极简依赖版**（v2 起）：运行必需的模块只有 `os` / `sys` / `socket`（Python 内核级，几乎任何环境都有）；`time` / `threading` / `webbrowser` 缺失时自动降级（分别影响：时间戳打印、并发处理、自动开浏览器）；`json` / `http.server` / `argparse` / `urllib` / `re` **完全不使用**——HTTP 协议手写解析，JSON 解析由浏览器端完成。

换句话说：只要 `python3 -c "import socket"` 不报错，服务器模式就能跑。

逐项打印 PASS/FAIL，全部 PASS 即可放心 `python3 server.py`。可能的 FAIL 与处理：

| FAIL 项 | 含义 | 应对 |
|---|---|---|
| http.server/json/argparse 等标准库缺失 | Python 太精简 | **双击 HTML 文件走浏览器模式**，核心功能不受影响 |
| webbrowser 缺失 | 只影响自动开浏览器 | `--no-browser` 启动，手动开浏览器输入地址 |
| 家目录不可写 | 文件在只读盘 | 换路径 `--dir /tmp/chaoji` |
| 无法绑端口 | 极少 | `--port` 换一个（1024 以上都不需要 root） |

**记住这句话：巢记 90% 的能力在你双击 HTML 那一刻就激活了，Python 只是让保存更无感。**

## 常见问题（FAQ）

**Q: 打不开文件提示"不是有效的巢记笔记本文件"？**
A: 选错了文件（不是 .nbk）或文件被损坏。检查文件扩展名；如果怀疑文件损坏，从备份恢复。

**Q: 保存后再打开发现是空的？**
A: 大概率是浏览器缓存被公司策略清了但**你仍用的是草稿**（未选过真实文件）。顶栏横幅「恢复草稿」可拿回最近的编辑。真正写进 .nbk 的内容不受影响。

**Q: 图片贴进去特别大，能缩吗？**
A: 点击图片，出现蓝框后拖右下角绿块。缩放会保存。

**Q: 关闭标签页之前忘了保存会丢吗？**
A: 默认 30 秒自动保存 + 关闭前弹确认，最多丢约 30 秒的输入。

**Q: Firefox 能用吗？**
A: 能打开和编辑，但 file:// 模式下**没有静默写回**（Firefox 不支持 FS Access API），保存会变成"下载文件"，需要手动覆盖同名文件。Linux 端建议直接用服务器模式。

**Q: 数据在服务器上吗？会传到公司服务器/云端吗？**
A: 不会。`server.py` 只绑定 `127.0.0.1`（本机回环），数据目录就是你指定的本地文件夹。**没有任何网络上传**。

**Q: 我能直接查看/编辑 .nbk 内容吗？**
A: 可以，它就是 UTF-8 JSON 文本（结构见下），用任意文本编辑器都行——当然推荐用巢记本身改，避免格式错误。

## 数据格式（给开发者）

```json
{ "app": "chaoji", "ver": 1,
  "notebooks": [ { "id": "...", "name": "笔记本",
    "sections": [ { "id": "...", "name": "分区",
      "pages": [ { "id": "...", "title": "...", "html": "...", "created": 0, "updated": 0 } ] } ] } ] }
```

浏览器 IndexedDB 只存"会话内崩溃恢复用的临时镜像"，不作为持久层。

**server.py API**：

| 端点 | 方法 | 作用 |
|---|---|---|
| `/api/ping` | GET | 服务探测（响应含 dataDir） |
| `/api/list` | GET | 列出数据目录所有 .nbk（含修改时间） |
| `/api/load/<file>` | GET | 读取指定 .nbk |
| `/api/save` | POST | `{file, state}` 原子写盘（临时文件+rename），文件名白名单防路径穿越 |

## 已知约束

- file:// 模式的静默写回依赖 Chromium ≥ 86（360 企业安全浏览器 v13 / Chrome / Edge / 360极速 均满足）；Firefox 降级为下载覆盖
- `navigator.storage.persist()` 在 file:// 下被浏览器拒绝，故 IndexedDB 只作会话内缓存
- 富文本存的是浏览器 native HTML，不同浏览器间打开可能有微小格式差异（如行高细节）
- 导出 Word 使用通用 HTML→.doc 方案，个别复杂排版（如表格内套图片）可能有轻微错位
